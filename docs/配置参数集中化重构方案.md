# 配置参数集中化重构方案

## Context（背景）

当前项目所有配置参数（相机IP、签名密钥、账号密码、端口号、API路径等）都硬编码在代码中，分散在 3 个文件共 15+ 处。用户后续可能更换其他品牌的摄像头，IP 和密钥都会变化，届时需要在代码里到处找这些参数来修改，维护困难。

本次重构的目标：**将所有可变参数提取到 `appsettings.json` 配置文件中，通过面向对象的配置类统一管理，用户换品牌时只需改配置文件，不动代码。**

## 方案设计

### 配置文件格式：JSON

选择 JSON 而非 App.config，理由：
1. 项目已有 `Newtonsoft.Json` 依赖，零新增依赖
2. JSON 语法简洁，对小白更友好，记事本即可编辑
3. 天然支持嵌套，可按逻辑分组（连接、API、流、预览）

### 新增文件（2个）

#### 1. `appsettings.json` - 配置文件

```json
{
  "Connection": {
    "_说明": "相机连接参数 - 换IP或账号密码时改这里",
    "DefaultIp": "192.168.0.15",
    "Username": "admin",
    "Password": "admin",
    "TimeoutSeconds": 10,
    "UserAgent": "YoloDetector/1.0"
  },
  "Api": {
    "_说明": "API接口参数 - 换品牌时改这里（签名密钥和接口路径）",
    "SignSecret": "f6fdffe48c908deb0f4c3bd36c032e72",
    "OldControlApiPath": "/control",
    "NewControlApiPath": "/xsw/control"
  },
  "Stream": {
    "_说明": "视频流参数 - {ip}、{port}、{channel}是占位符，会自动替换",
    "RtspPort": 554,
    "RtspUrlFormat": "rtsp://{ip}:{port}/stream{channel}",
    "MaxChannel": 7
  },
  "Preview": {
    "_说明": "预览参数 - 相机Web预览页面路径和状态刷新间隔(毫秒)",
    "PreviewPagePath": "/draw.html",
    "StatusRefreshIntervalMs": 5000
  }
}
```

#### 2. `AppConfig.cs` - 配置类 + 配置管理器

包含：
- `CameraConfig` 类：4个嵌套子类（ConnectionConfig、ApiConfig、StreamConfig、PreviewConfig），所有属性都有默认值
- `AppConfig` 静态类：单例管理器，程序启动时自动加载 `appsettings.json`，文件缺失或损坏时安全回退到代码中的默认值
- `StreamConfig.GetRtspUrl(ip, channel)` 方法：根据模板生成RTSP地址，体现面向对象的"数据+行为"封装

访问方式示例：`AppConfig.Current.Connection.DefaultIp`、`AppConfig.Current.Api.SignSecret`

### 修改文件（4个）

#### 3. `YoloDetector.csproj` - 添加配置文件复制设置

新增 ItemGroup，设置 `appsettings.json` 为 `PreserveNewest`（只在源文件更新时复制，不覆盖用户在输出目录的修改）。

#### 4. `ApiSignUtil.cs` - 1处改动

- 第16行：删除 `DefaultSecret` 常量
- 第61行：`DefaultSecret` 改为 `AppConfig.Current.Api.SignSecret`

#### 5. `CameraApiClient.cs` - 6处改动

- 构造函数：超时时间、User-Agent 从配置读取
- 第295-296行：默认账号密码从配置读取
- 第311/390/443行：`"/control"` 改为 `AppConfig.Current.Api.OldControlApiPath`
- 第374/427/527行：`"/xsw/control"` 改为 `AppConfig.Current.Api.NewControlApiPath`
- 第441行：`"admin:admin"` 改为从配置拼接
- 第568-572行：`GetVideoStreamUrl` 方法使用 `AppConfig.Current.Stream.GetRtspUrl()`

**不改动：** `/jsonfile/ip`、`/jsonfile/cpu` 等状态查询路径保持硬编码。这些是相机内部API的深层实现，过于细碎，换品牌时需要重写整个类，放入配置反而增加臃肿。

#### 6. `MainForm.cs` - 5处改动

- 第110行：`statusTimer.Interval = 5000` → `AppConfig.Current.Preview.StatusRefreshIntervalMs`
- 第227行：`txtIp.Text = "192.168.0.15"` → `AppConfig.Current.Connection.DefaultIp`
- 第293行：流地址初始化 → `AppConfig.Current.Stream.GetRtspUrl(...)`
- 第347-351行：`numChannel.Maximum = 7` → `AppConfig.Current.Stream.MaxChannel`
- 第860行：fallback IP → `AppConfig.Current.Connection.DefaultIp`
- 第876行：`"/draw.html"` → `AppConfig.Current.Preview.PreviewPagePath`

## 实施顺序

1. 创建 `appsettings.json` 配置文件
2. 创建 `AppConfig.cs` 配置类和管理器
3. 修改 `YoloDetector.csproj` 添加复制设置
4. 修改 `ApiSignUtil.cs`（改动最小，1处）
5. 修改 `CameraApiClient.cs`（改动最多，6处）
6. 修改 `MainForm.cs`（UI层，5处）
7. 编译验证

## 验证方法

1. **编译验证**：`dotnet build` 确保零错误零警告
2. **运行验证**：启动程序，确认界面默认值正确（IP显示192.168.0.15、流地址正确）
3. **配置文件验证**：修改 `appsettings.json` 中的 IP 为其他值，重启程序，确认界面输入框的默认IP随之变化
4. **功能验证**：点击"连接相机"，确认连接功能正常
5. **容错验证**：删除 `appsettings.json`，重启程序，确认程序不崩溃且使用默认值
