> 💡 **小白必学知识点**：
> 
> **什么是接口（Interface）？**
> 
> 接口就像一份"合同"，它定义了类必须实现的方法，但不包含具体实现。通过接口，可以实现"品牌解耦"：
> 
> 1. `ICameraApi` 定义了所有相机都应该有的方法（连接、获取状态、控制推拉流等）
> 2. `ANGEHUACameraApiClient` 实现了这些方法（针对ANGEHUA品牌）
> 3. 如果换品牌，只需创建新的实现类（如`HikCameraApiClient`）
> 4. `MainForm` 只依赖接口，不需要修改任何代码

> **什么是工厂模式？**
> 
> `CameraApiFactory` 根据配置文件中的品牌标识，自动创建对应的API实例。就像一个工厂，根据订单（配置）生产不同的产品（API实例）。

> **什么是多品牌配置解耦？**
> 
> 多品牌配置解耦是指将不同品牌相机的配置分开管理，每个品牌一个独立的配置文件：
> 
> 1. **主配置文件**（appsettings.json）：存放全局配置和当前激活的品牌
> 2. **品牌配置文件**（cameraConfigs/{品牌}.json）：存放特定品牌的所有配置
> 3. **切换品牌**：只需修改主配置中的 `ActiveCameraConfig` 字段
> 4. **优势**：各品牌配置互不干扰，切换品牌无需修改大量配置项

```csharp
            // 通过注册表设置FEATURE_BROWSER_EMULATION为11001，强制使用IE11模式

            // 启用视觉样式（让界面更美观）
            Application.EnableVisualStyles();
            
            // 设置兼容文本渲染（确保字体显示正常）
            Application.SetCompatibleTextRenderingDefault(false);
            
            // 启动主窗体
            Application.Run(new MainForm());
        }
        
        // 设置WebBrowser控件的IE版本模拟
        private static void SetWebBrowserEmulationMode()
        {
            try
            {
                string appName = Assembly.GetExecutingAssembly().GetName().Name + ".exe";
                using (RegistryKey key = Registry.CurrentUser.CreateSubKey(
                    @"Software\Microsoft\Internet Explorer\Main\FeatureControl\FEATURE_BROWSER_EMULATION"))
                {
                    // 11001 = IE11 Edge模式
                    key.SetValue(appName, 11001, RegistryValueKind.DWord);
                }
            }
            catch (Exception ex)
            {
                System.Diagnostics.Debug.WriteLine("WebBrowser IE11模式设置失败: " + ex.Message);
            }
        }
    }
}
```

### 3.3 ANGEHUACameraApiClient.cs - ANGEHUA品牌相机实现

这是ANGEHUA（安格华）品牌相机的具体实现类，实现了ICameraApi接口。与XSW不同，ANGEHUA相机**仅通过RTSP协议接入**，没有HTTP API。

#### 3.3.1 ANGEHUA相机特点

ANGEHUA（安格华）相机**仅通过RTSP协议接入**，没有HTTP API：

- **连接协议**：仅RTSP
- **HTTP API**：不支持
- **视频流地址**：`rtsp://{ip}:554/ch01.264`
- **连接测试**：TCP端口测试（554）

> 💡 **小白必学知识点**：
> 
> **什么是RTSP协议？**
> 
> RTSP（Real-Time Streaming Protocol）是专门用于实时视频流传输的协议，端口号通常是554。与HTTP协议不同：
> - HTTP是短连接，请求-响应模式
> - RTSP是长连接，持续传输视频数据
> 
> ANGEHUA相机只提供RTSP流，没有HTTP管理接口，所以：
> - 无法通过API获取设备状态（CPU、内存等）
> - 无法通过API控制推拉流
> - 只能直接播放RTSP流

### 3.4 CameraApiFactory.cs - API工厂类

这是一个简单工厂类，根据配置文件中的品牌标识创建对应的API实例：

```csharp
public static class CameraApiFactory
{
    public static ICameraApi Create(string ip)
    {
        // 获取配置中的相机品牌
        string brand = AppConfig.Current.Api.CameraBrand.ToUpper();
        
        // 根据品牌创建对应的实现类
        switch (brand)
        {
            case "ANGEHUA":
                // ANGEHUA（安格华）- 通过RTSP协议接入，无HTTP API
                return new ANGEHUACameraApiClient(ip);
            
            case "HIK":
                // 海康威视（尚未实现），使用默认实现（ANGEHUA）
                System.Diagnostics.Debug.WriteLine("HIK品牌尚未实现，使用默认实现(ANGEHUA)");
                return new ANGEHUACameraApiClient(ip);
            
            case "DAHUA":
                // 大华（尚未实现），使用默认实现（ANGEHUA）
                System.Diagnostics.Debug.WriteLine("DAHUA品牌尚未实现，使用默认实现(ANGEHUA)");
                return new ANGEHUACameraApiClient(ip);
            
            default:
                // 未知品牌，使用默认实现（ANGEHUA）
                System.Diagnostics.Debug.WriteLine("未知相机品牌: " + brand + ", 使用默认实现(ANGEHUA)");
                return new ANGEHUACameraApiClient(ip);
        }
    }
}
```

> 💡 **小白必学知识点**：
> 
> **如何添加新品牌相机？**
> 
> 只需3步：
> 
> 1. **创建新的实现类**（如`HikCameraApiClient`），实现`ICameraApi`接口
> 2. **在工厂类中添加case分支**，返回新的实现类实例
> 3. **修改配置文件**，将`CameraBrand`设置为新品牌标识
> 
> **不需要修改MainForm！** 因为MainForm只依赖`ICameraApi`接口。

### 3.5 AppConfig.cs - 配置管理器

这是一个非常重要的类，负责管理所有配置参数，实现了配置的集中化管理。

#### 3.5.1 配置文件格式（主配置文件 appsettings.json）

主配置文件非常简洁，只包含品牌切换控制：

```json
{
  "_说明": "主配置文件 - 全局配置和品牌切换控制",
  "ActiveCameraConfig": "ANGEHUA"
}
```

> 💡 **小白必学知识点**：
> 
> 主配置文件只需要一个字段 `ActiveCameraConfig`，因为：
> 1. 所有具体配置都在品牌配置文件中（cameraConfigs/{品牌}.json）
> 2. 代码中的 `CameraConfig` 类定义了默认值，即使品牌配置文件缺失也能运行
> 3. 切换品牌只需修改这一个字段，非常方便

#### 3.5.2 读取配置的方法

```csharp
// 读取相机默认IP
string ip = AppConfig.Current.Connection.DefaultIp;

// 读取签名密钥
string secret = AppConfig.Current.Api.SignSecret;

// 读取相机品牌（新增）
string brand = AppConfig.Current.Api.CameraBrand;

// 读取API路径（新增，换品牌时修改）
string ipApiPath = AppConfig.Current.Api.IpApiPath;
string cpuApiPath = AppConfig.Current.Api.CpuApiPath;

// 读取RTSP端口
int port = AppConfig.Current.Stream.RtspPort;

// 生成RTSP流地址
string rtspUrl = AppConfig.Current.Stream.GetRtspUrl("192.168.0.15", 0);
// 结果: "rtsp://192.168.0.15:554/stream0"
```

#### 3.5.3 配置类特点

> 💡 **小白必学知识点**：
> 
> 1. **静态类**：`AppConfig`是静态类，不需要创建实例，直接通过类名调用
> 2. **默认值机制**：如果配置文件不存在，程序会使用代码中定义的默认值
> 3. **自动加载**：程序启动时自动加载配置文件
> 4. **防崩溃设计**：配置文件损坏时不会崩溃，自动回退到默认值
> 5. **集中管理**：所有参数都在appsettings.json中，修改方便
> 6. **多品牌解耦**：品牌配置独立存放，切换品牌只需修改 `ActiveCameraConfig` 字段

#### 3.5.4 多品牌配置加载逻辑

程序启动时，配置加载流程如下：

```
程序启动
    ↓
加载主配置文件 (appsettings.json)
    ↓
读取 ActiveCameraConfig 字段（如 "ANGEHUA"）
    ↓
加载品牌配置文件 (cameraConfigs/ANGEHUA.json)
    ↓
┌─────────────────────┐
│ 文件存在且有效？     │
└─────────┬───────────┘
     是 ↓           ↓ 否
使用品牌配置    使用代码默认值
    ↓                ↓
配置加载完成    配置加载完成
```

**加载规则**：
- 主配置文件只读取 `ActiveCameraConfig` 字段，用于确定使用哪个品牌配置
- 品牌配置文件存在时，**直接替换**为完整配置（不再合并）
- 品牌配置文件不存在或解析失败时，使用代码中定义的默认值

#### 3.5.5 切换品牌的方法

**方法1：修改配置文件（推荐）**

只需修改 `appsettings.json` 中的 `ActiveCameraConfig` 字段：

```json
// 切换到海康威视
"ActiveCameraConfig": "HIK"

// 切换到大华
"ActiveCameraConfig": "DAHUA"

// 切换到安格华（ANGEHUA，RTSP协议）
"ActiveCameraConfig": "ANGEHUA"
```

**方法2：代码切换**

```csharp
// 切换到海康威视配置
AppConfig.LoadBrandConfig("HIK");

// 切换到安格华配置（RTSP协议）
AppConfig.LoadBrandConfig("ANGEHUA");

// 获取当前可用的品牌配置列表
string[] brands = AppConfig.GetAvailableBrandConfigs();
// 返回: ["ANGEHUA", "HIK", "DAHUA"]
```

**方法3：保存品牌配置**

```csharp
// 将当前配置保存为新的品牌配置文件
AppConfig.SaveBrandConfig("NEW_BRAND");
// 会创建 cameraConfigs/NEW_BRAND.json
```

#### 3.5.5 品牌配置目录结构

```
cameraConfigs/
├── ANGEHUA.json      ← 安格华品牌配置（RTSP协议，无HTTP API）
├── HIK.json          ← 海康威视品牌配置
├── DAHUA.json        ← 大华品牌配置
└── YOUR_BRAND.json   ← 自定义品牌配置（按需添加）
```

**添加新品牌的步骤**：

1. 在 `cameraConfigs` 目录下创建新的配置文件（如 `YOUR_BRAND.json`）
2. 在配置文件中填写该品牌特有的API路径和参数
3. 修改主配置中的 `ActiveCameraConfig` 为新品牌名称
4. （可选）创建对应的API实现类（如 `YourBrandCameraApiClient`）

```csharp
        return;
    }
    
    // 第三步：添加时间戳
    string time = DateTime.Now.ToString("yyyy-MM-dd HH:mm:ss");
    
    // 第四步：显示在界面上
    txtLog.AppendText("[" + time + "] " + message + "\r\n");
    
    // 第五步：自动滚动到最新日志（方便查看）
    txtLog.ScrollToCaret();
}
```

> 💡 **小白必学知识点**：
> 
> `AddLog`方法会做两件事：
> 1. 调用`Logger.Write()`将日志写入文件（永久保存）
> 2. 将日志显示在界面上的txtLog控件中（临时查看）
> 
> 这样即使关闭程序，日志也会保存在文件中，方便以后查看和排查问题。

#### 3.3.4 视频预览方案（LibVLC）

程序使用**LibVLC方案**直接播放RTSP流，稳定性高，不依赖浏览器。

| 方案 | 技术原理 | 优点 | 缺点 |
|------|----------|------|------|
| LibVLC | 直接播放RTSP流 | **稳定性高**，不依赖浏览器，延迟低，画面流畅，支持RTSP认证 | 需要先开启RTSP拉流 |

#### LibVLC方案关键优化说明

> 💡 **重要优化点**：
> 
> 1. **实例复用**：`LibVLC`、`MediaPlayer`、`VideoView` 实例全局复用，仅 `Media` 对象每次创建新实例。这是因为：
>    - `LibVLC` 是重量级对象，频繁创建销毁会导致性能问题和渲染异常
>    - `Media` 对象绑定了特定的流地址，切换流时必须重新创建
> 
> 2. **事件去重**：注册事件前先取消注册（`mediaPlayer.Playing -= MediaPlayer_Playing`），防止事件重复触发
> 
> 3. **直播缓存优化**：设置 `:live-caching=1500` 和 `:network-caching=1500`，解决画面卡顿问题
> 
> 4. **RTSP认证**：支持通过配置文件设置用户名密码（`--rtsp-user`、`--rtsp-pwd`）
> 
> 5. **自动重连**：RTSP直播流意外停止时自动重新连接
> 
> 6. **状态标记**：使用 `isUserStopping` 标记区分用户主动停止和意外停止

#### 关键代码 - LibVLC方案

```csharp
private void StartVideoPreviewWithLibVLC()
{
    // 1. 获取RTSP流地址
    string rtspUrl = txtStreamUrl.Text.Trim();
    if (string.IsNullOrEmpty(rtspUrl))
    {
        int channel = (int)numChannel.Value;
        rtspUrl = AppConfig.Current.Stream.GetRtspUrl(cameraIp, channel);
    }
    
    // 2. 确保LibVLC实例已创建（全局只创建一次，重量级对象）
    if (libVLC == null)
    {
        string username = AppConfig.Current.Connection.Username;
        string password = AppConfig.Current.Connection.Password;
        string libvlcArgs = "--network-caching=1000";
        if (!string.IsNullOrEmpty(username))
        {
            libvlcArgs += $" --rtsp-user={username}";
        }
        if (!string.IsNullOrEmpty(password))
        {
            libvlcArgs += $" --rtsp-pwd={password}";
        }
        libVLC = new LibVLC(libvlcArgs);
    }
    
    // 3. 停止当前播放（如果有）并释放Media对象
    if (mediaPlayer != null)
    {
        // 先取消事件注册（避免重复注册）
        mediaPlayer.Playing -= MediaPlayer_Playing;
        mediaPlayer.Stopped -= MediaPlayer_Stopped;
        mediaPlayer.EncounteredError -= MediaPlayer_EncounteredError;
        
        mediaPlayer.Stop();
        media?.Dispose();
        media = null;
    }
    
    // 4. 创建或复用MediaPlayer
    if (mediaPlayer == null)
    {
        mediaPlayer = new MediaPlayer(libVLC);
    }
    
    // 5. 创建或复用VideoView控件
    if (videoView == null)
    {
        videoView = new VideoView();
        videoView.Dock = DockStyle.Fill;
        videoView.BackColor = Color.Black;
        videoPanel.Controls.Add(videoView);
    }
    
    // 6. 设置VideoView的MediaPlayer
    videoView.MediaPlayer = mediaPlayer;
    
    // 7. 创建Media对象并设置选项（关键优化）
    media = new Media(libVLC, rtspUrl, FromType.FromLocation);
    media.AddOption(":rtsp-tcp");           // TCP传输，更稳定
    media.AddOption(":rtsp-frame-buffer-size=500000");  // 增大帧缓冲区
    media.AddOption(":no-audio");           // 禁用音频
    media.AddOption(":live-caching=1500");  // 增大直播缓存，解决画面卡顿
    media.AddOption(":network-caching=1500");  // 增大网络缓存
    media.AddOption(":clock-jitter=0");     // 减少时钟抖动
    media.AddOption(":sout-keep");          // 保持流输出
    
    // 8. 设置媒体到播放器
    mediaPlayer.Media = media;
    
    // 9. 注册播放器事件（先取消再注册，确保不重复）
    mediaPlayer.Playing -= MediaPlayer_Playing;
    mediaPlayer.Playing += MediaPlayer_Playing;
    mediaPlayer.Stopped -= MediaPlayer_Stopped;
    mediaPlayer.Stopped += MediaPlayer_Stopped;
    mediaPlayer.EncounteredError -= MediaPlayer_EncounteredError;
    mediaPlayer.EncounteredError += MediaPlayer_EncounteredError;
    
    // 10. 开始播放
    mediaPlayer.Play();
    
    // 11. 启动流保活定时器（检测卡顿并自动重连）
    streamKeepAliveTimer.Start();
}
```

## 五、软件使用教程

### 5.1 启动程序

1. 打开 `bin/Release/publish/` 目录
2. 双击 `YoloDetector.exe` 启动程序
3. 程序启动后会显示主界面

### 5.2 连接相机

**步骤1：输入相机IP地址**
- 在左侧「相机连接配置」区域，输入相机IP地址（默认：`192.168.0.15`）

**步骤2：点击「连接相机」按钮**
- 程序会测试与相机的网络连接
- 如果连接成功，状态会显示「已连接」（绿色）
- 如果连接失败，会弹出错误提示

**连接成功后的效果**：
- 下方的设备状态信息会自动更新
- 视频流地址会自动填充
- 定时器会每5秒刷新一次设备状态

### 5.3 查看摄像头画面

**步骤1：确保相机已连接**
- 状态必须显示「已连接」

**步骤2：点击「开始预览」按钮**
- 程序会自动开启RTSP拉流
- 等待1秒后开始播放视频
- 右侧视频预览区域会显示摄像头画面

**注意事项**：
- 首次预览可能需要等待2-5秒（RTSP连接建立需要时间）
- 如果画面一直黑屏，请检查：
  - 相机是否已经开启视频输出
  - 网络是否通畅
  - 防火墙是否阻止了554端口

### 5.4 停止预览

点击「停止预览」按钮，程序会：
- 停止视频播放
- 释放视频资源
- 清空视频预览区域

### 5.5 推拉流控制

**开启拉流**：点击「开启拉流」按钮，相机开始输出RTSP流

**开启推流**：点击「开启推流」按钮，相机会把视频推送到指定的RTMP服务器

### 5.6 断开连接

点击「断开连接」按钮，程序会：
- 停止视频预览
- 停止设备状态刷新
- 断开与相机的所有连接

### 5.7 查看设备状态

设备状态信息区域会显示：
- IP地址
- CPU使用率
- 内存使用率
- 磁盘总量/可用
- 录像总数
- 带宽信息
